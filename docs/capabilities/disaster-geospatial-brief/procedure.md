# 재난·공간 브리프

## 사용 범위
- 기상청 예보, 수위·유량, 미세먼지 조회
- 응급실·대피·공공시설의 공개 위치정보 조사
- 여러 관측값을 하나의 상황 브리프로 정리

## 실행 경계
- 출동·대피·의료 판단을 자동 결정하지 않는다.
- 실시간이라는 표현은 관측시각과 갱신주기가 확인될 때만 쓴다.
- 민감 시설·경호 동선·개인 위치를 노출하지 않는다.

## 절차
1. 대상 위치, 반경, 기준시각, 필요한 관측값을 확인한다.
2. 기관별 공식 데이터와 갱신시각을 조회한다.
3. 주소·좌표·관측소 불일치를 해소한다.
4. 위험 신호와 데이터 공백을 구분한다.
5. 즉시 연락해야 할 공식 기관과 수동 판단 항목을 표시한다.

## 출력 계약
- 위치·기준시각·출처
- 관측값과 갱신주기
- 데이터 공백·충돌
- 자동 의사결정 미수행 및 수동 확인 항목

## 실행 도구

- fixture 검증: `python3 -m kgov_runtime.capabilities.disaster_geospatial_brief --fixture`
- live 조회: `runtime-contract.md`의 credential·endpoint 조건을 확인한 뒤 실행합니다.
- fixture 통과는 live endpoint 검증을 의미하지 않습니다.
