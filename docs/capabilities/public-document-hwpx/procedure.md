# 공공문서·HWPX

## 사용 범위
- 공문, 보고서, 서식의 본문·표·필드 구조 파악
- HWP/HWPX 원본과 변환본의 누락·변형 점검
- 검토 가능한 Markdown/JSON/HWPX 초안 작성

## 실행 경계
- 기본은 읽기와 초안 작성이다.
- 원본 파일을 덮어쓰거나 전자문서시스템에 제출하지 않는다.
- 개인정보·비공개 정보는 출력 전에 마스킹한다.

## 절차
1. 원본 경로, 문서 형식, 필요한 산출물을 확인한다.
2. 사용 가능한 parser/converter를 확인하고, 없으면 설치를 추측하지 말고 blocker를 보고한다.
3. 제목·문단·표·첨부·서식 필드를 구조화한다.
4. 변환 결과를 원본과 대조해 누락·깨짐·문자 인코딩을 점검한다.
5. 초안과 원본 변경 여부, 확인이 필요한 항목을 분리해 보고한다.

## 출력 계약
- 입력 파일과 사용 도구
- 구조화 결과 또는 초안
- 누락·변형·민감정보 위험
- 원본 변경/제출 여부

## 실행 도구

- fixture 검증: `python3 -m kgov_runtime.capabilities.public_document_hwpx --fixture`
- 상세 입력·권한·중단 조건은 `references/runtime-contract.md`를 따릅니다.
- fixture 통과는 live endpoint 또는 실제 문서 검증을 의미하지 않습니다.
