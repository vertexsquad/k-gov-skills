# 복지·보건·안전 조사

## 사용 범위
- 복지·연금·지원사업과 기관 정보 검색
- 응급실·검진·장기요양기관 조회
- 식품·의약품 공개 안전정보 확인

## 실행 경계
- 복지 수급자격, 의학적 진단, 복약·치료를 확정하지 않는다.
- 주민번호·건강정보·처방정보를 저장하거나 출력하지 않는다.
- 긴급 상황은 공식 긴급전화와 의료진 판단으로 전환한다.

## 절차
1. 지역, 대상자 범주, 기준일, 필요한 정보 범위를 최소화한다.
2. 공식 기관·공공데이터의 최신 안내를 확인한다.
3. 자격조건·운영시간·기관상태·안전주의를 구조화한다.
4. 개인 상황에 적용하려면 담당기관 확인이 필요한 항목을 표시한다.
5. 사실 조회와 상담·진단 영역을 분리해 보고한다.

## 출력 계약
- 공식 출처와 기준일
- 조건·기관·연락처 요약
- 자격/진단 미확정 표시
- 개인정보 취급 및 긴급전환 경계

## 실행 도구

- fixture 검증: `python3 -m kgov_runtime.capabilities.welfare_health_safety_research --fixture`
- live 조회: `runtime-contract.md`의 credential·endpoint 조건을 확인한 뒤 실행합니다.
- fixture 통과는 live endpoint 검증을 의미하지 않습니다.
