# 한국 법령·의안 조사

## 사용 범위
- 법령의 현행 조문·시행일·개정 이력 확인
- 국회 의안·표결과 지방 조례·회의록 조사
- 판례·행정규칙·기관 안내의 권위 수준 구분

## 실행 경계
- 법률자문이나 사건 결과를 확정하지 않는다.
- 로그인·결제·소송 제출은 자동화하지 않는다.
- 현행성 확인 없는 블로그·요약문을 최종 근거로 쓰지 않는다.

## 절차
1. 관할, 기준일, 법령/의안/사건 식별자를 확정한다.
2. 국가법령정보·국회·법원·지방의회 등 공식 출처를 우선 조회한다.
3. 조문, 시행일, 상태, 관련 개정·표결을 교차확인한다.
4. 사실, 해석, 확인 필요를 분리한다.
5. 출처 URL·문서번호·조회시각을 포함한 근거표를 작성한다.

## 출력 계약
- 질문과 기준일
- 공식 근거표
- 상충·폐지·시행 전 여부
- 비법률자문 경계와 추가 확인 사항
