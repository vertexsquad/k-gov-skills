# 민원 분류·답변 초안

## 사용 범위
- 비식별 처리된 민원의 쟁점과 요청사항 요약
- 관련 법령·공식 안내와 담당 소관 후보 조사
- 중복·반복 민원 구분 및 담당자 검토용 답변 초안 작성

## 실행 경계
- 원문에 개인정보·민감정보가 남아 있거나 비식별 여부가 불명확하면 중단한다.
- adapter의 식별자 검사는 방어 수단일 뿐 완전한 개인정보 탐지를 보장하지 않는다.
- 소관, 처분, 수급·허가·제재, 법적 결론을 확정하지 않는다.
- 답변을 국민신문고·전자문서·메일 등에 발송하거나 등록하지 않는다.

## 절차
1. `python3 -m kgov_runtime.capabilities.civil_complaint_triage_draft`로 입력 크기·비식별 확인·기본 식별자 패턴을 검사한다.
2. 통과한 민원에서 확인된 사실, 민원인의 요청, 해석이 필요한 부분을 분리한다.
3. 국가법령정보·정부기관 안내 등 현행 공식 출처에서 근거와 소관 후보를 확인한다.
4. 요약, 분류, 근거표, 답변 초안, 확인 필요 항목을 작성한다.
5. 담당 공무원의 소관·사실·법적 근거 검토와 발송 승인을 요청한다.

## 출력 계약
- 민원 요약과 요청사항
- 분류·소관 후보 및 불확실성
- 공식 근거표와 기준일
- 담당자 검토용 답변 초안
- 개인정보·법적 판단·발송 관련 수동 검토 항목

## 실행 도구
- fixture 검증: `python3 -m kgov_runtime.capabilities.civil_complaint_triage_draft --fixture`
- 로컬 입력 검사: `python3 -m kgov_runtime.capabilities.civil_complaint_triage_draft <redacted-input.json>`
- 입력 계약과 중단 조건은 `runtime-contract.md`를 따른다.
- fixture 통과는 실제 민원 처리나 개인정보 검증 완료를 의미하지 않는다.
