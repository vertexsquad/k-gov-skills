# 공공조달 조사

## 사용 범위
- G2B 발주계획·입찰공고·부정당제재 조회
- S2B 학교장터와 D2B 국방조달 공개공고 조회
- 공고번호·발주기관·일정·자격요건 비교

## 실행 경계
- 투찰, 계약, 서명, 결제, 인증서 사용을 수행하지 않는다.
- 공고 첨부와 정정공고를 읽지 않고 자격을 단정하지 않는다.
- 업체 위험등급이나 위법 여부를 자동 판정하지 않는다.

## 절차
1. 조달망, 공고유형, 기관, 기간, 키워드를 확정한다.
2. 공식 공개 표면에서 공고번호와 최신 상태를 확인한다.
3. 본문·첨부·정정·마감시각·참가자격을 구조화한다.
4. 제재정보는 사업자번호와 유효기간을 정확 일치로 확인한다.
5. 사실표와 담당자 확인이 필요한 판단을 분리한다.

## 출력 계약
- 공고/계획 번호와 공식 URL
- 일정·기관·금액·자격요건
- 정정·첨부·제재 확인 결과
- 투찰·계약 미수행 표시

## 실행 도구

- fixture 검증: `python3 skills/public-procurement-research/scripts/adapter.py --fixture`
- live 조회: `references/runtime-contract.md`의 credential·endpoint 조건을 확인한 뒤 실행합니다.
- fixture 통과는 live endpoint 검증을 의미하지 않습니다.
