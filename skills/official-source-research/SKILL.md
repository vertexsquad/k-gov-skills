# 공식출처 리서치

## 사용 범위
- 정책·기관·기업·문화·교육·지역생활 정보 조사
- 공식 웹, 공공데이터, 공시, 보도자료의 근거표 작성
- domain 전용 Skill이 없을 때 안전한 공통 조사 절차 제공

## 실행 경계
- 비공개 시스템, 로그인 뒤 개인정보, 유료·제출 기능에 접근하지 않는다.
- 공식 출처가 없으면 일반 웹 추론을 사실처럼 승격하지 않는다.
- 민감업무는 공개정보와 manual-review 범위로 제한한다.

## 절차
1. 질문, 관할기관, 기준일, 필요한 산출물을 정의한다.
2. 공식 기관·법정 시스템·공공데이터를 우선 탐색한다.
3. 문서번호·URL·발행일·갱신일과 원문 인용을 보존한다.
4. 상충하거나 오래된 정보는 현재성 차이를 표시한다.
5. 확인된 사실, 계산·요약, 비공식 추론, 미확인을 분리한다.

## 출력 계약
- 질문과 조사 범위
- 공식 출처 근거표
- 사실·추론·미확인 분리
- 인증·개인정보·외부행동 미수행 표시

## 실행 도구

- fixture 검증: `python3 skills/official-source-research/scripts/adapter.py --fixture`
- 상세 입력·권한·중단 조건은 `references/runtime-contract.md`를 따릅니다.
- fixture 통과는 live endpoint 또는 실제 문서 검증을 의미하지 않습니다.
